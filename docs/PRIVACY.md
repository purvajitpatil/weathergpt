# WeatherGPT — Privacy Policy

## Data Collection

### What We Collect

| Data | Purpose | Retention |
|------|---------|-----------|
| Location (browser GPS) | Weather lookup | Session only (not stored without permission) |
| Saved locations | User convenience | Until user deletes |
| Language preference | UI localization | Until user changes |
| Weather queries | Provide answers | Session only |
| Conversation history | User reference | Session only |

### What We Do NOT Collect

- Exact GPS coordinates (stored as city-level)
- Browsing history
- Device fingerprinting
- Social media profiles
- Financial information
- Health data
- Biometric data

## Location Data

- Location is obtained only with explicit browser permission
- Stored only as city/district level (not precise coordinates)
- Used only to provide relevant weather data
- Never sold or shared with third parties
- User can delete saved locations at any time

## Weather Data

All weather data comes from public sources:
- **Open-Meteo** (GFS/ICON/ECMWF models) — CC-BY 4.0
- Weather data is factual and non-personal

## Third-Party Services

| Service | Purpose | Data Sent |
|---------|---------|-----------|
| Open-Meteo | Weather data | Location coordinates |
| Open-Meteo Geocoding | City lookup | Search query |
| Gemini (Google) | AI explanations | Weather evidence + user query |
| Open-Meteo Air Quality | AQI data | Location coordinates |

## Data Security

- HTTPS in production
- No plaintext passwords
- Parameterized SQL queries (no injection)
- Rate limiting (abuse prevention)
- Structured logging (no PII)

## User Rights

Users can:
1. View what data is stored about them
2. Delete their saved locations
3. Delete their account
4. Opt out of conversation history storage
5. Use the service without creating an account

## Children's Privacy

WeatherGPT is not directed at children under 13.
No data is knowingly collected from children.

## Changes to Policy

Material changes will be communicated via the application.
